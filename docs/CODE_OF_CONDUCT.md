
# AIQuantTradingResearch Code of Conduct

**Status:** Active
**Version:** 1.0
**Last Updated:** 2026-08-06
**Maintainers:** AIQuantTradingResearch Team

---

# Purpose

AIQuantTradingResearch is an open-source engineering project built on collaboration, curiosity, professionalism, and continuous learning.

This Code of Conduct defines the expected behavior for everyone participating in the project, including maintainers, contributors, reviewers, and community members.

Our goal is to create an environment where technical discussions are respectful, inclusive, and focused on solving problems together.

---

# Our Values

We value:

- Professionalism
- Respect
- Curiosity
- Collaboration
- Constructive feedback
- Continuous improvement
- Engineering excellence

Technical disagreements are expected.

Disrespect is not.

---

# Expected Behavior

Contributors are encouraged to:

- Treat others with respect.
- Assume positive intent.
- Welcome different perspectives.
- Provide constructive and actionable feedback.
- Support newcomers.
- Share knowledge openly.
- Focus discussions on technical merit.
- Admit mistakes and learn from them.
- Help improve documentation.
- Celebrate contributions of all sizes.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination of any kind.
- Personal attacks.
- Insults or abusive language.
- Trolling or intentionally disruptive behavior.
- Publishing private information without permission.
- Deliberately misleading contributors.
- Repeatedly ignoring project standards.
- Any behavior that creates an unsafe or hostile environment.

---

# Engineering Discussions

Engineering decisions should be based on:

- Evidence
- Trade-offs
- Technical reasoning
- Maintainability
- Simplicity
- Long-term sustainability

Discussions should focus on ideas rather than individuals.

Questions and respectful challenges are encouraged.

---

# Code Reviews

Code reviews are opportunities for learning and collaboration.

Reviewers should:

- Explain suggestions clearly.
- Be respectful.
- Focus on improving the code.
- Recognize good work.
- Separate personal preferences from objective improvements.

Authors should:

- Accept constructive feedback professionally.
- Ask questions when clarification is needed.
- Be open to revising their implementation.
- Remember that review comments target the code, not the individual.

---

# Community Culture

We aim to cultivate a community where people feel comfortable:

- Asking questions.
- Sharing ideas.
- Proposing improvements.
- Reporting mistakes.
- Experimenting with new approaches.

Learning is considered a success, even when an experiment does not produce the expected outcome.

---

# Reporting Concerns

If you experience or witness behavior that violates this Code of Conduct, please contact the project maintainers through GitHub Discussions or by opening a private communication channel when appropriate.

Reports will be handled respectfully, confidentially when possible, and with the goal of maintaining a healthy community.

---

# Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the situation, maintainers may:

- Request clarification.
- Provide guidance.
- Remove inappropriate content.
- Restrict participation.
- Suspend or permanently remove contributors whose behavior repeatedly violates these principles.

Actions will always aim to protect the health of the project and its community.

---

# A Living Document

This Code of Conduct may evolve as the project grows.

Changes should reflect the project's core values while continuing to foster a respectful, collaborative, and technically focused community.

Engineering excellence begins with how we collaborate.
