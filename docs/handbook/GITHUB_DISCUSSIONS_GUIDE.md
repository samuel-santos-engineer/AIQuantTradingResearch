# Purpose

GitHub Discussions is the collaborative knowledge space for AIQuantTradingResearch.

Unlike Issues, which track actionable work, Discussions are intended for exploring ideas, asking questions, sharing knowledge, and collaborating on engineering topics.

Discussions help preserve valuable technical conversations that may later influence architecture, implementation, or project direction.

---

# Discussions vs. Issues

Use **Discussions** when you want to:

* Ask questions
* Brainstorm ideas
* Discuss architecture
* Share research
* Explore alternatives
* Request feedback
* Present experiments
* Share lessons learned

Use **Issues** when work can be planned, assigned, prioritized, and completed.

# Discussion Guidelines

When starting a discussion:

* Provide sufficient context.
* Explain the motivation.
* Share supporting references when applicable.
* Be open to constructive feedback.
* Focus on collaborative problem-solving.

Healthy technical disagreement is encouraged when conducted respectfully.

---

# Engineering Culture

AIQuantTradingResearch values thoughtful technical conversations.

Discussions should prioritize:

* Curiosity
* Respect
* Transparency
* Evidence-based reasoning
* Continuous learning
* Long-term thinking

The objective is not simply to reach answers, but to improve collective engineering knowledge.

---

# Relationship to the Engineering Handbook

Important conclusions from Discussions may influence:

* Engineering Decision Log
* Architecture Decision Records (ADRs)
* Product Vision
* Roadmap
* Coding Standards
* Dependency Guidelines

Knowledge generated through collaboration should become part of the project's permanent engineering documentation whenever appropriate.

---

# Guiding Statement

Every meaningful engineering conversation is an opportunity to improve the project.

GitHub Discussions exists to transform ideas into shared knowledge and, ultimately, into better engineering decisions.
