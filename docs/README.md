# Documentation Principles

The documentation follows these principles:

- Documentation is treated as code.
- Every significant technical decision must be documented.
- Documentation evolves together with the source code.
- Documentation should explain **why**, not only **how**.
- Documents should remain concise, accurate, and version controlled.
