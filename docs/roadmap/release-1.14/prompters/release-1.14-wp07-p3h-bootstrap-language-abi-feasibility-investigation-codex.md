## Nonnegotiable architecture
Approved root is a **finite secret-free privileged bootstrap PID1**, which forks router and guardian bootstraps and retains unprivileged UID/GID1200 supervisor as PID1. Router bootstrap permanently drops to 1100; guardian bootstrap forks agent bootstrap before incompatible privilege drops, then guardian permanently drops to 1300; agent bootstrap permanently drops to 1000 and execs the agent, which parents the UI. Supervisor directly parents router and guardian; guardian directly parents agent. No privileged helper remains. All role identity values remain conditional on actual base-image collision checks.

- D1 guardian obtains actual positive bounded child-specific kernel wait proving agent **normal exit zero**; D2 supervisor independently obtains actual positive bounded wait proving guardian **normal exit zero**; supervisor separately proves router exit zero after host disposal. No ECHILD, EOF, notifier, process absence, pidfd readiness or namespace teardown as substitute proof. Exclusive status ownership and no competing reapers/SIGCHLD auto-reaping.
- D3 container/namespace teardown is failure containment only. T2 adopted-child drain and terminal absence follow required positive waits.
- One propagated absolute `CLOCK_MONOTONIC` shutdown deadline (4 seconds); Docker stop grace 5 seconds. Privileged bootstrap deadline 5 seconds and total startup deadline 30 seconds; no resetting relative budgets.
- Fixed descriptor design: S SR3/SG4/metadata5; G SG3/gate4/metadata5; R credential3/RA4/SR5/metadata6; agent RA3/metadata4 survives exec, validates once then closes; UI exec has no control, credential, metadata or gate FDs. Agent-bootstrap **FD5** is a conditionally approved gate slot, **not** a proven native allocation. Explicit alias closure and collision-safe remapping required; CLOEXEC is only a backstop.
- C1 guardian `A_EXEC` → agent-bootstrap `A_EXEC_ACK` acknowledges receipt only; gate and all aliases close before agent exec; post-exec A_READY remains distinct. Frozen launch IDs, PID binding, sequence, metadata, startup and exposure ordering remain unchanged.
- No public listener before `R_EXPOSE`; no production credential ingress or authenticated-client testing. Disabled Option A remains unchanged. `PUBLIC_RUNTIME_VERIFIED=False`; production, public-runtime and Azure **NO-GO**.
