# C2B-25 — immutable chart candidate contract

Contract frozen before candidate generation, 2026-10-16. Schema `aiq-chart-handoff-candidate-v1`; not a production release/export/promotion contract. Baseline `33b941c28b0158810b4f406db965bf83ff92244a`; open planning PR #346 remains separate and unmerged.

Layout: `manifest.json` plus exactly twelve files ordered by interval `1h,4h,1d`, then range `1D,7D,30D,90D`, named `<interval>-<range>.json`. No links, directories, extra files or partial versions. Manifest fields, in order: `schema`, `generatorVersion`, `seed`, `files`. Each entry: `name`, `bytes`, `sha256`. SHA-256 is lowercase hex over exact file bytes. An externally pinned manifest digest in reader code anchors the entire candidate; self-reported checksums alone are insufficient. This candidate pin is not independent production qualification.

Each selection uses the existing LocalSyntheticChart.Payload shape, camelCase properties in declaration order, UTF-8 without BOM, compact System.Text.Json default escaping, and exactly one final LF (no CR). Decimal strings have exactly four OHLC, three volume and twelve SMA fractional digits; no exponent, whitespace, sign prefix or leading zero padding. UTC timestamps are exactly `yyyy-MM-ddTHH:mm:ssZ`, ascending interval grid, no duplicate/gap. JSON duplicate/extra members and nonfinite numbers are invalid.

Payload includes the exact simulation label, instrument `btc-like-simulation`, interval/range, coverage `[2025-10-26T00:00:00Z,2026-10-01T00:00:00Z)`, frozen dataset/window fingerprints, `aiq-ta-v1`, calculation start, warmup=250, calculationCount=visible+250 and publicRuntimeVerified=false. Only visible end-anchored rows are present: timestamp, OHLCV and C# SMA20. Fixed 12 selections; count = range-days*24/interval-hours. All visible SMA samples are positive/non-null and aligned. No other indicator publication is qualified by this contract. Existing generator/calculator/E4 bytes and local adapter stay unchanged.

Candidate engineering caps (not F1 measurements): manifest <=8192 bytes; member <=1048576 bytes; all members plus manifest <=4194304 bytes; exactly 13 files; at most 2160 visible rows/member. Reader allows one validation operation at a time, no waiting queue, no global dataset cache, and at most one selected response in existing Streamlit session state. It checks a two-second monotonic budget between reads/parse steps; this is cooperative, not a hard CPU/RSS/filesystem-I/O deadline. Bounded bytes/counts limit work; actual latency/memory and multi-session F1 budgets remain unqualified. No startup/background generation or validation; each acquisition validates the complete finite manifest/member set before releasing the selected immutable in-memory response. No repair, fallback or network source.

Offline operator: `AIQ_IMMUTABLE_EXPORT=1`, `DOTNET_ENVIRONMENT=Development`, exact `--write-immutable-chart-candidate <new-output-directory>`, no WEBSITE-prefixed keys. Output directory must not exist; linked ancestors rejected. Producer is operator-only, not selected by deployed config or request processing. On failure leave an untrusted incomplete candidate for operator inspection, never promote it. No artifacts committed; Docker build context excludes `_immutable_chart_candidate`. Local demonstration copies only this owned output to `python/presentation/_immutable_chart_candidate`; reader accepts no user/config-supplied artifact path. Root and ancestors must be real directories, members regular files, no links/reparse points; Linux ownership and no group/other write permissions required below the application boundary. Complete validation uses opened file descriptors, checks file metadata before/after read, and retains parsed selected bytes rather than reopening for rendering. Runtime-writable code/anchor or ancestors is not production isolation proof.

Candidate UI mode: explicit `AIQ_IMMUTABLE_CHART_CANDIDATE=1`, Development, numeric loopback Streamlit address, and no Azure WEBSITE keys, on Windows or Linux. No public startup changes or Azure opt-in. Missing/invalid/disabled artifacts return generic unavailable via BridgeError, never a filesystem detail or provider fallback. PUBLIC_RUNTIME_VERIFIED stays False; public APIs stay 503 DATASET_NOT_READY. Existing Windows live local source is separate and takes no part in immutable reads. Ambiguous simultaneous local/immutable flags fail closed.

Producer and candidate gate also reject inherited TWELVEDATA/VIKE, persistence, replay and visualization environment setting names. Local operator commands must use a dedicated scrubbed development terminal; never remove Azure WEBSITE identity markers to bypass the Azure denial. This environment refinement does not alter serialized bytes or the frozen handoff schema.

Promotion boundary: governance business strategy sections 12.1–12.8 require independent full derived parity, trusted ownership, complete-read admission, resource/isolation qualification and separate production/export/promotion decisions. C2B-25 authorizes these temporary candidate artifacts only. Do not copy them into an Azure image, activate UI publicly, change APIs or readiness, or treat local bytes/hashes as accepted public release evidence. WP07 ON HOLD; deployment/activation NO-GO.

Evidence, exact commands, hashes, tests and per-site rollback/readiness gaps will be recorded in the companion C2B-25 evidence report after execution. No runtime acceptance is implied by this specification.
