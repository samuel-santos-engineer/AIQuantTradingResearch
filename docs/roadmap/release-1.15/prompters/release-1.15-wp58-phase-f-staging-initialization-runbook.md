Bootstrap exits on failure and execs the existing API only after success/disposal of initializer ownership.

Per-symbol commits remain separate. Interruption can leave partial state; this is a serve-transition gate, NOT pair-atomic transactions or a new global API readiness contract. Existing general `serve` can still expose honest missing-data responses; strict mode does not add an unconditional restart readiness gate.
