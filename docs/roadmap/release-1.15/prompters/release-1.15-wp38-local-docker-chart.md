Fixture key material exists only in the disposable fixture directory and server-side process environments. The UI has no SQLite/PFX mount. No key enters browser URLs/bundles or committed evidence.

The unchanged API adapter is server-side `ResearchSnapshotClient` calling authenticated `POST /v1/research/snapshot` over verified HTTPS. Request: schemaVersion `1.0`, instrument `BTC/USD` or `ETH/USD`, canonical string requestEpoch, knownIdentity null or a validated identity. Response includes at most 1,000 chronological unique UTC candle-opening timestamps with decimal-string open/high/low/close and actual **fixture** base-asset volume, aligned analytics/status and generation/version/display-date identity. It is a transformed educational presentation DTO, never a raw-price endpoint. UI uses the established **one-minute timeframe**, with 100/300/1,000 retained-candle range presets; presets count candles, not elapsed minutes when a gap exists. No unimplemented hourly/daily resampling is advertised. The full bounded series remains loaded for historical navigation; the preset sets the viewport. There is no arbitrary unbounded date query.

Missing/wrong key returns 401; unsupported instrument 422; query-string range injection 400. Verified empty snapshots, missing datasets, invalid input, unavailable research and malformed responses use existing fail-closed API/client/UI states. Anonymous health is only process liveness, exact `200 Alive`, not data readiness. Source status is conveyed by the explicit local fixture mode and manifest; the frozen API schema was not extended with an unsupported provenance field.

## Launch from this branch (Windows PowerShell 5.1)

Prerequisites: local Linux/amd64 Docker Desktop, .NET SDK 10 and existing NuGet package cache, Python 3.13, and existing cached images listed below. No cloud credentials or installed cloud services are needed. Preparation refuses missing images instead of pulling them and restores only from an empty local feed plus the existing package cache. Missing inputs stop with a local-step failure; this workflow does not install packages. Use a **new temporary directory**; existing output is never overwritten. The TLS fixture expires after one day: prepare a new fixture directory after expiry. Port 8501 must be free or choose `-Port 18538` consistently.

```powershell
$demo = Join-Path $env:TEMP 'aiq-r115-wp38-demo'
.\eng\docker\release-1.15\Invoke-Wp38LocalChart.ps1 -Action Prepare -Directory $demo
.\eng\docker\release-1.15\Invoke-Wp38LocalChart.ps1 -Action Start -Directory $demo -Port 8501
# Open http://127.0.0.1:8501 ; select BTC/USD or ETH/USD and retained-candle range.
.\eng\docker\release-1.15\Invoke-Wp38LocalChart.ps1 -Action Stop -Directory $demo -Port 8501
```

The wrapper restores the prior process environment in finally. Do not use an actual service key with this fixture workflow. Stop preserves the owned state volume, image and stopped containers for another Start; it does not delete unrelated resources or the retained state. A subsequent Start verifies session ownership, removes that session's stopped containers/networks, then recreates them. Only one running writer may attach the volume.

The agent host blocks `.ps1` execution under its normal policy. No policy change/bypass was made. The same engine was actually qualified through these supported Python entry commands:

```powershell
python -B eng/docker/release-1.15/wp38_prepare_local.py --output "$env:TEMP/aiq-r115-wp38-demo" --action Prepare
python -B eng/docker/release-1.15/wp38_prepare_local.py --output "$env:TEMP/aiq-r115-wp38-demo" --action Start --port 8501
python -B eng/docker/release-1.15/wp38_prepare_local.py --output "$env:TEMP/aiq-r115-wp38-demo" --action Stop --port 8501
```
