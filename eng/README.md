
# Engineering Platform

The `eng/` directory contains the engineering tooling that supports
AIQuantTradingResearch.

The assets contained here are responsible for building, validating,
formatting, testing, and maintaining the repository.

Production application code must never depend on artifacts inside
this directory.

Conversely, the engineering platform may orchestrate operations
across the entire repository.

The objective is to provide a reproducible, automated, and
maintainable engineering experience for every contributor.
